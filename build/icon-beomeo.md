# Hot pink Beomeo icon

Edited from `build/icon.png` using the built-in image generation tool.
The final PNG is `build/icon-beomeo.png`; the window copy is
`src/main/static/icon-beomeo.png`. The Windows ICO contains PNG images at
16, 24, 32, 48, 64, 128 and 256 pixels, converted using Sharp.

Final image edit prompt:

> Precise recolor of attached original app icon. Clean flat vector-like icon,
> exact same circular white disk, thick colored ring with small downward pointed
> tab at bottom, and right-pointing rounded triangle centered inside. Replace
> green with uniform solid hot pink (#FF1493), white stays pure white. No texture,
> no gradients, no red pixels, no stray marks or flecks anywhere. Silhouette must
> have smooth perfectly clean antialiased edges. Transparent background, empty
> transparent padding 7% on all sides; entire shape contained with nothing
> touching image borders. Square canvas. No new elements, no text. This is a
> small Windows app icon, clarity at small sizes essential.
